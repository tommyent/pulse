The Codex pet now lets go of its memory when you aren't using it.

- **Codex stops when the pet is idle.** Once you opened the pet's chat, Codex and the MCP servers it runs kept going until you quit Pulse or hid the pet. Now they stop on their own once the card has been closed with nothing running for five minutes. A call, a running helper or a report on its way keeps them going.
- **Your conversation stays.** Opening the card again starts Codex back up and picks up the same conversation, with its messages still on screen. New conversation still starts fresh.

For Apple silicon Macs on macOS 26 or later. To check the download, run `shasum -a 256 -c Pulse-0.4.1.dmg.sha256` in the folder that holds both files.
