A ring for your coding agents, themes you can write yourself or have an agent write, a new sculpted look, and Settings with a sidebar.

- **An agents ring.** With [Rex](https://www.superlogical.com/rex), Superlogical's terminal (in beta for Mac), **Settings → Agents → Show agents on the rail** adds a ring under the Codex pet for the Claude Code, Codex, Antigravity and Grok agents open in Rex, on this Mac and the Macs Rex connects to. It turns orange while an agent waits for you and red when one fails, and its number counts the agents at work until one needs you. Its card lists them, idle ones last with how long they've been idle; click a row, or press **⌥⌘K** and use the arrow keys, to see that agent's pane in Rex. You can add a sound and an alert in the middle of the screen; both wait during breaks, calls and a locked screen. It's off by default.
- **Themes.** **Settings → Appearance** has a mode (Auto, Light or Dark) and lets you choose and preview a theme for each look. Ten new themes come with Pulse: Abyss, Espresso Brass, Forest Canopy, Glacier, Linen, Matcha Washi, Newsprint, Orchard, Synthwave Chrome and Velvet. A theme is one JSON file in Pulse's Themes folder, read again as soon as it changes. Copy one of Pulse's own, use **Import…** or **Export…**, or drop a file on Settings. **Copy Agent Prompt** asks a coding agent to read the guide in the Themes folder and make a theme there.
- **Finishes and wallpapers.** **Default** uses the theme's own finish. Under **Finish · Beta**, **Liquid** uses clear glass, **Glass** uses regular glass, and **Frosted** adds a light frost over regular glass. Pick a wallpaper for each look and use the crop editor to move, zoom or rotate the image on the rail and cards.
- **Groove.** A sculpted look beside Classic: each ring's colour lies on the floor of a channel pressed into a raised slab. **Groove White** and **Groove Black** are its light versions.
- **Settings has a sidebar** of panes instead of tabs along the top, with Pulse's version at its foot. **About Pulse** in the menu bar menu shows the version too.
- **New colours in Classic.** A black surface with a glossy highlight at the top left, a lighter track so an empty ring still shows on it, a deeper Codex blue, and Antigravity's pools in indigo (Gemini) and aqua (Claude and GPT), where they were violet and sky blue.
- **Grok usage by product.** When Grok reports a breakdown, the card shows each product's share of the credits used that period. Near-limit alerts use the overall limit.
- **Fixes.** One stalled Antigravity usage check no longer stops the Antigravity ring for good. Pulse stops the run safely and tries again once agy has run on its own, or once more half an hour later. After a network failure, the card shows the cause and Pulse backs off before retrying. Pausing breaks now cancels a countdown already on screen. When a break ends, or the pet's card closes, the app you were using gets the keyboard back. When the Claude card has no numbers it explains whether you're offline, rate limited (HTTP 429) or there was a server error, with its code. The Ideas level slider in **Settings → Breaks** has a name for VoiceOver.
- **Breaks and battery.** Break history survives a failed save, and time spent on a completed break no longer counts again as time away. Critical battery alerts can appear while a Codex approval is open.
- **Settings and refresh.** The wallpaper and sound pickers open without freezing Settings. Unrelated settings changes leave the rail where it is. **Refresh usage** is the only control that clears a pause in Antigravity polling. **Manage Themes** shows theme file problems as warnings.

For Apple silicon Macs; tested on macOS 26 and 27. To check the download, run `shasum -a 256 -c Pulse-0.5.0.dmg.sha256` in the folder that holds both files.
