# Pulse themes

Colour themes for Pulse's rail, usage cards and menu. Each theme is one JSON file, and the picture beside it is that theme drawn by Pulse itself.

## Install a theme

1. Download the theme's `.json` file.
2. In Pulse, open Settings › Appearance and click **Import…**, or drop the file onto that pane. You can also put the file straight into Pulse's Themes folder (**Show in Finder** on the same pane opens it): Pulse picks it up by itself.
3. Choose it in the **Light theme** or **Dark theme** menu. A light theme is listed under Light theme, a dark one under Dark theme, and one marked "any" under both.

## About the pictures

- Each picture is drawn with Pulse's own views on a grey background. It shows the usage card, the rail opened (the agents ring; rings that are empty, full and at the limit, and one from an older refresh; the battery and the break cup) and the rail at rest.
- In these pictures a flat theme's usage bars come out grey. In Pulse they take the ring's colour.
- Amber Terminal Glass sits on Liquid Glass, which can't be drawn this way, so its picture is a screenshot of Pulse running over a dark desktop.

## Make your own

Pulse's Themes folder holds a guide, `AGENTS.md`, that describes every key in a theme file. To have a coding agent make a theme for you, use **Make one with an agent** in Settings › Appearance: it copies one line telling the agent where the folder and its guide are.
